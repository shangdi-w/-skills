# 09 - 综合免杀策略（18条核心实战思路）

## 方法论层

### 1. 纵深防御（Defense in Depth for Attackers）
不依赖单一技术，多层次堆叠：
```
Layer 1: 编译混淆 → Layer 2: 静态加密 → Layer 3: 动态解密
→ Layer 4: 内存操作 → Layer 5: 行为伪装 → Layer 6: 通信隐蔽
```

### 2. 环境感知（Environment-Aware）
执行前检测：CPU核心数、内存大小、磁盘大小、运行时间、进程数量、窗口/对话框存在、鼠标移动、安装的软件列表 → 异常则延迟或退出

### 3. 分阶段执行（Staged Execution）
```
Phase 1: Dropper（纯净，无恶意行为）
Phase 2: 下载器（下载加密payload）
Phase 3: 解密器（内存中解密）
Phase 4: 注入器（注入到合法进程）
Phase 5: 载荷执行
```
每个阶段独立编译，不同混淆方式

### 4. 时间逃逸（Temporal Evasion）
- Sleep/Hibernate（避开沙箱的时间限制）
- 只在特定时间段执行（上班时间/非工作时间）
- 延迟执行：随机30-120秒后激活
- 心跳/心跳检查

### 5. 域前置与C2隐匿
- CDN前置（Cloudflare/Azure/CloudFront）
- HTTPS + 合法证书
- 伪装流量为Teams/Skype/OneDrive/Windows Update
- 心跳随机化

### 6. 反沙箱
- 检测CPU数量、内存、磁盘
- 检测鼠标移动
- 检测运行时间
- 检测是否有对话框/活动窗口
- 检测是否有杀软进程

### 7. 反逆向
- 代码虚拟化（VMProtect/Themida）
- 反调试API（IsDebuggerPresent, NtQueryInformationProcess）
- 异常处理钩子
- 代码自修改

### 8. 反内存扫描
- 避免RWX内存（RW → RX分阶段）
- 模块践踏（覆盖合法DLL的.text段）
- 页面加密（执行后加密，需要时再解密）
- INT3指令屏蔽（每次仅1条指令可见）

### 9. 反API Hook
- 间接syscall
- 手动映射ntdll（从磁盘读干净副本）
- Halo's Gate / Hell's Gate（从被hook函数中恢复SSN）
- 重新加载DLL（从KnownDLLs）

### 10. 反事件追踪（Anti-ETW）
- Patch EtwEventWrite
- Block EtwTi（Threat Intelligence）
- COM对象劫持

## 技术实战层

### 11. 单文件免杀（避免DLL侧加载检测）
整个payload编译为单个exe，静态链接所有依赖

### 12. 无新线程执行
使用回调API（CallWindowProc, EnumFonts, CertEnumSystemStore）或APC或纤程

### 13. 内存分配技巧
- 使用 NtAllocateVirtualMemory 代替 VirtualAlloc
- 使用 HeapCreate(HEAP_CREATE_ENABLE_EXECUTE)
- 使用 MapViewOfFile 映射文件到内存
- 使用 Section 对象（NtCreateSection）

### 14. 利用合法进程
- Process Hollowing (svchost.exe)
- Process Doppelganging
- Process Herpaderping
- DLL侧加载/代理DLL
- 父进程欺骗（PPID Spoofing）

### 15. 绕过数字签名检查
- SigThief窃取合法签名
- 从无签名的白名单程序注入
- 利用系统进程（system32下的程序在UAC下不会被检测）

### 16. 文件系统规避
- 不写文件到磁盘（全内存执行）
- 写入到合法目录（C:\ProgramData\Microsoft\...）
- 使用NTFS ADS（交换数据流）隐藏
- 文件名伪装（.txt, .log, .tmp）

### 17. 注册表规避
- 使用WMI Event Subscription代替Run键
- 计划任务持久化
- COM劫持

### 18. 持续对抗迭代
- 定期检查payload是否被杀
- 维护多个变体随时切换
- 每周更新生成参数
- 跟踪最新AV更新日志
- 社区分享免杀经验

## 策略组合矩阵

| 目标 | 技术组合 | 难度 | 效果 |
|------|---------|------|------|
| 过Defender | 加密 + Gobfuscate + 分阶段内存 | 低 | 稳定 |
| 过火绒 | 间接syscall + 回调执行 | 中 | 稳定 |
| 过360核晶 | 全链路 + 环境感知 + 进程镂空 | 高 | 稳定 |
| 过ESET | 间接syscall + PE头混淆 | 中高 | 需测试 |
| 过卡巴斯基 | 全链路 + 多级加密 + 合法进程注入 | 高 | 需持续对抗 |
| 过CrowdStrike | 间接syscall + ETW Patch + 无新线程 | 高 | 部分绕过 |
| 过SentinelOne | 模块践踏 + 间接syscall + 行为伪装 | 高 | 需验证 |
